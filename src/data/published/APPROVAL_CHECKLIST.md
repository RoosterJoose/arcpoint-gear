# Published Article Approval Checklist

Use this checklist before converting a reviewed OpenClaw draft from `src/content-inbox/` into approved data in `src/data/published/`.

- [ ] Schema valid
- [ ] Product URLs verified
- [ ] Affiliate links verified
- [ ] Image usage reviewed
- [ ] Sources reviewed
- [ ] No exact prices
- [ ] No Amazon review counts
- [ ] No copied Amazon descriptions
- [ ] No fake field testing
- [ ] Disclosure visible
- [ ] SEO title/meta checked
- [ ] Schema output checked
- [ ] Build passed
